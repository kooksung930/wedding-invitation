# Google Drive 사진 업로드 버전

## 설치

1. Google Drive에서 `새로 만들기 → 더보기 → Google Apps Script`를 엽니다.
2. `Code.gs` 내용을 붙여넣습니다.
3. `파일 추가 → HTML`로 `Index` 파일을 만들고 `Index.html` 내용을 붙여넣습니다.
4. `배포 → 새 배포 → 웹 앱`을 선택합니다.
5. 실행 주체는 `나`, 액세스 권한은 `모든 사용자`로 설정합니다.
6. 처음 한 번 Drive 권한을 승인합니다.
7. 배포된 웹 앱 URL을 QR 코드와 모바일청첩장 버튼에 사용합니다.
